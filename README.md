# UCB APOD 🚀

No APOD, as estrelas não estão apenas no céu – elas estão em pixels na sua tela! É como um presente cósmico diário da NASA, entregando instantâneos alucinantes do espaço que fazem você se sentir como se estivesse montando cometas e dançando entre galáxias. Cada foto vem com um passe para os bastidores - uma explicação geek de estrelas do rock espacial (também conhecidas como astrônomos) que desvendam os mistérios das maravilhas celestiais. De tesouros telescópicos a fotos amadoras de outro mundo, o APOD tem o universo na discagem rápida, servindo um banquete cósmico que transformará qualquer um em um aficionado pelo espaço!

### Tecnologias Utilizadas

#### JavaScript
Para trazer as imagens estelares até você, utilizamos JavaScript para fazer requisições à API da NASA APOD. Esse código busca diariamente as últimas imagens do cosmos, trazendo novas janelas para o universo diretamente para a sua tela. Este é o motor que alimenta nossa jornada estelar, garantindo que você nunca perca a maravilha celestial do dia.

#### Python com Flask e EasyGoogleTranslate
A magia da tradução acontece nos bastidores, graças ao Python e ao framework Flask. Utilizamos a biblioteca EasyGoogleTranslate para converter as descrições das imagens de estrelas e galáxias para um idioma mais acessível, tornando o universo compreensível para todos. Nosso servidor Flask processa essas traduções com eficiência e rapidez, assegurando que cada explicação astronômica seja tão clara quanto o céu noturno.

#### HTML, CSS e Tailwind
O visual do site é construído com HTML e CSS utilizando o framework Tailwind CSS. Esse conjunto de utilidades proporciona um design moderno e responsivo, permitindo que a interface se adapte a qualquer tamanho de tela e oferecendo uma experiência estelar em dispositivos móveis ou desktops. Também utilizamos Three.js para uma visualização interativa do sistema solar.
